GitHub のリポジトリを、URL ひとつで動かす

リポジトリとブランチを指定するだけで、開発用のサーバーが立ち上がり、友だちにも見せられるプレビューURLが発行されます。

GitHub でログイン
ログインに使うのは、GitHub のユーザー名とアイコンだけです。
  1. ログインGitHub のアカウントでログインします。初めての人は、管理者の承認を待ちます。
  2. リポジトリを指定URL、ブランチ、ポートを入れて「作成して起動」。Dockerfile が無くても、Node / Django / FastAPI / Flask は自動で判定します。
  3. プレビューを開くビルドが終わると、https://〜-dev.… のURLで開けます。
  • プライベートリポジトリも、GitHub App で許可したものだけ読み取れます(読み取りのみ)。
  • 使い続けているかを、一定時間ごとに確認します。応答がないと、自動で停止します。
  • 停止しても、書き込んだデータは残ります。再ビルドや設定変更をすると消えます。
  • 実行できる数と、メモリ・CPU は、制限されています。
